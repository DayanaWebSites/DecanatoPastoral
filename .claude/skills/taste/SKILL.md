# Taste (Decanato Pastoral Social)

Read before generating UI. Source: Leonxlnx/taste-skill.

## Do

1. Read `SIGMA_OMEGA/DIRECTIVES/eureka-design/00-readme.md` and `08-anti-patterns.md`
2. Use the logo palette in `src/styles/global.css` only
3. Institutional, calm, readable. Adults mayores are part of the audience
4. One H1. Real H2/H3 hierarchy. Serif for titles, Inter for UI
5. Photos: comedores with faces already blurred. No new faces without the pipeline

## Do not

- Purple-to-blue hero gradients or the SIGMA accent `#7144f5`
- Nested cards without purpose
- Glassmorphism, neon shadows, text gradients
- Invented phones, emails, mass times, or parish services
- Client-side islands "por si acaso"
- Hardcoded institutional copy in a `.astro`
